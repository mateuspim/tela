# tela 1.0.1

First signed GitHub release, versionCode **2**, for **Android 10+**.

- **Full:** download `tela-full.apk` to update the existing `cc.pym.tela` app.
  It uses the same signing certificate as the saved owner build (1.0.0, code 1).
- Play, Wallhaven-only, and Safe are separate installations with isolated data.
- Includes private-library offload recovery and all four edition builds.
- `SHA256SUMS` covers all APKs and the Play bundle, including the stable Full alias.

Open the downloaded APK and confirm Update. Wait for transfers/offloads to
finish first. Never uninstall to resolve an update error: it deletes private
images, the database, and keys. An update on the physical tablet has not been
tested for this release.

[Latest Full APK](https://github.com/mateuspim/tela/releases/latest/download/tela-full.apk)
(requires a GitHub account with access to this private repository).
