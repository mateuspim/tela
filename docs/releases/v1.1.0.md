# tela 1.1.0

versionCode **5**, for **Android 10+**. Every edition updates in place over
1.0.3; the update was tested on the physical tablet (Safe and Wallhaven).

## Every edition has the private library now

- **Safe and Play** gain the private library, its screenshot blocking and the
  optional fingerprint/face/PIN lock. They still have no API key and no
  explicit content. Before this, Safe offered "Private library" as a download
  destination with no screen to open it, so anything sent there was
  unreachable — it now appears in Library.
- These editions now declare `USE_BIOMETRIC` for that lock. It is a normal
  permission: nothing is asked at install, and tela never sees biometric data.

## Downloads and storage

- *Download all* on a tag files everything under that tag without looking up
  each wallpaper's tags first.
- Granting a folder that is already called `tela` writes straight into it,
  instead of into `tela/tela/`. An existing `tela/tela/` keeps working.
- Deleting (or retagging away) the last wallpaper of a tag removes its empty
  folder — in the private library, the Files destination and the Gallery.
- The download chooser lays out in two columns on wide screens, so nothing is
  cut off on a landscape tablet.
- Settings shows "Where files are saved" as soon as a folder has been chosen,
  not only when a default sends downloads there.

## Smaller fixes

- File sizes read like `323 KB`, and counts are grouped (`19,714 wallpapers`).
- On a tablet, TalkBack can reach Browse, Library and Settings again.
- Safe and Play no longer mention an API key or explicit content in Settings.
- "Remove from history?" can be cancelled in every edition.

## Installing

Open the downloaded APK and confirm **Update**. Never uninstall to resolve an
update error: it deletes private images, the database, and keys.

[Latest Full APK](https://github.com/mateuspim/tela/releases/latest/download/tela-full.apk)
(requires a GitHub account with access to this private repository).
